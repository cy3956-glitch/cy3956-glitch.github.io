PCY Studio 홈페이지 아이콘 복구 수정본
=====================================

이번 수정본은 이전 업데이트에서 글자(P/F/B/C)로 대체되어 사라졌던 브랜드 이미지를
실제 기존 디자인 이미지로 다시 복구한 버전입니다.

복구된 이미지
- PCY Studio 실제 로고
- PickGo 실제 앱 아이콘
- FieldLog 실제 앱 아이콘
- BabyLog 실제 앱 아이콘/브랜드 이미지
- CarLog 실제 앱 아이콘

업로드 방법
1. ZIP 압축을 풉니다.
2. index.html / styles.css / script.js / assets 폴더를
   cy3956-glitch.github.io 저장소 루트에 업로드합니다.
3. 같은 이름 파일은 Replace/덮어쓰기 합니다.
4. Commit changes를 누릅니다.

주의
- assets 폴더도 반드시 같이 올려야 아이콘과 배경/영상이 정상 표시됩니다.
- 이번 파일은 직전 PickGo 중심 홈페이지 디자인은 유지하면서 아이콘만 실제 브랜드 자산으로 복구한 수정본입니다.
