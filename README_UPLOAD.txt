PCY Studio 홈페이지 - 헤더 로고 크기 수정본
========================================

수정 내용
- 왼쪽 상단 PCY 로고가 512px 원본 크기로 튀어나오던 문제 수정
- 헤더 로고를 PCY 큐브 전용 소형 아이콘으로 변경
- HTML 자체에 38x38 크기를 직접 고정해 CSS 캐시가 남아도 커지지 않게 처리
- styles.css / script.js에 버전값을 붙여 GitHub Pages/브라우저 캐시 갱신
- PickGo / FieldLog / BabyLog / CarLog 실제 아이콘은 그대로 유지

업로드
1. ZIP 압축 해제
2. 저장소 루트에 index.html / styles.css / script.js / assets 폴더를 모두 덮어쓰기
3. Commit changes
4. 사이트에서 Ctrl+F5로 한 번 새로고침

assets 폴더도 반드시 같이 덮어써 주세요.
