PCY Studio 홈페이지 업데이트 패키지
================================

1. ZIP 압축을 풉니다.
2. 안의 index.html, styles.css, script.js, assets 폴더를
   GitHub 저장소 cy3956-glitch/cy3956-glitch.github.io 의 루트에 업로드합니다.
3. 기존 파일과 같은 이름이 있으면 교체(Replace)합니다.
4. Commit changes를 누릅니다.
5. GitHub Pages 반영까지 보통 잠시 걸립니다.

포함 내용
- PickGo 메인 히어로
- 바다/카페 실사형 배경
- PickGo 홍보 영상
- 실제 PickGo 버블 설정/원터치/상점 화면
- PickGo 주요 기능
- FieldLog / BabyLog / CarLog 앱 카드
- 모바일 반응형 UI

참고
- PickGo와 BabyLog는 정확한 Google Play 패키지 주소를 확인하지 못해
  Google Play 검색 링크를 사용했습니다.
- FieldLog와 CarLog는 알려진 패키지 주소를 연결했습니다.
