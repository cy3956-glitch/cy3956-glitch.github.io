1초컷

개인정보처리방침

시행일: 2026년 9월 15일

1초컷은 게임 기록 및 설정을 앱 기능 제공을 위해 기기에 저장할 수 있습니다.

1. 처리하는 정보

앱은 사용자가 직접 입력하거나 선택한 기록, 설정 및 첨부 데이터를 기능 제공을 위해 처리할 수 있습니다. 앱에서 별도의 회원가입을 요구하지 않는 경우, 개발자는 사용자의 이름·전화번호 등 직접 식별 정보를 별도로 수집하기 위한 자체 회원 서버를 운영하지 않습니다.

2. 저장 및 이용 목적

사용자가 입력한 데이터는 기록 저장, 조회, 검색, 통계, 백업/복원 등 앱의 핵심 기능을 제공하기 위해 사용됩니다. 데이터는 기본적으로 사용자의 기기 내부 저장공간에 저장될 수 있습니다.

3. 사진·파일·카메라 접근

앱 기능에 사진 첨부, 촬영, 파일 선택 또는 백업 기능이 포함된 경우 사용자가 해당 기능을 실행할 때 필요한 권한을 요청할 수 있습니다. 해당 접근은 사용자가 기능을 이용하는 범위에서만 사용됩니다.

4. 광고 및 외부 서비스

앱은 Google AdMob과 같은 광고 서비스를 사용할 수 있습니다. 이 경우 광고 제공업체가 광고 제공, 부정 사용 방지, 측정 등의 목적으로 기기 정보, 광고 식별자 및 관련 기술 정보를 처리할 수 있습니다. 외부 서비스의 데이터 처리는 해당 서비스 제공업체의 정책을 따릅니다.

5. 개인정보의 제3자 제공

개발자는 사용자가 앱에 직접 입력한 개인 기록을 임의로 판매하지 않습니다. 법령상 의무가 있거나 사용자가 직접 선택한 외부 서비스 기능을 사용하는 경우를 제외하고, 자체적으로 수집한 개인 기록을 제3자에게 판매하는 것을 목적으로 하지 않습니다.

6. 보관 및 삭제

기기에 저장된 앱 데이터는 앱의 삭제 기능, 앱 데이터 삭제 또는 앱 제거 등을 통해 삭제될 수 있습니다. 사용자가 직접 생성한 백업 파일은 사용자가 저장한 위치에서 직접 관리해야 합니다.

7. 아동 관련

앱이 아동의 기록을 다루는 경우에도, 해당 기록은 보호자 또는 사용자가 직접 입력하는 정보입니다. 개발자는 아동의 개인정보를 별도의 자체 서버에 수집하기 위한 회원가입 기능을 제공하지 않는 것을 원칙으로 합니다.

8. 방침의 변경

앱 기능, 광고·분석 서비스 또는 관련 법령의 변경에 따라 본 방침은 수정될 수 있습니다. 중요한 변경이 있는 경우 앱 또는 개발자 웹사이트를 통해 안내할 수 있습니다.
