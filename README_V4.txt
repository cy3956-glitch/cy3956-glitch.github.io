PCY Studio Developer Website V4
========================

가장 쉬운 적용 방법
1. 이 ZIP을 풉니다.
2. GitHub 저장소 cy3956-glitch/cy3956-glitch.github.io 로 이동합니다.
3. ZIP 안의 모든 파일/폴더를 저장소 루트에 업로드합니다.
4. 같은 이름의 index.html이 있으면 V2 index.html로 교체합니다.
5. app-ads.txt는 기존 내용과 동일하게 유지됩니다.
6. Commit changes를 누릅니다.

- 앱별 실제 홍보 이미지 카드 적용
